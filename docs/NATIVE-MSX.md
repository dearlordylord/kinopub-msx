# Отдельный клиент KinoPub для MSX: проверяемый кандидат

2026-10-24. Это подготовленная замена маршрута воспроизведения, а не подтверждение исправленного звука на Samsung.

Клиент: https://dearlordylord.github.io/kinopub-msx/public/start.json

Существующий стартовый параметр телевизора не изменён. Lampa не удалена.

## Что изменено

Кнопка просмотра открывает список реальных аудиодорожек выбранной серии. Выбор передаёт свежий HLS URL встроенному проигрывателю MSX через `video:resolve:request:interaction:`. HTML-видеоплагин больше не используется этим маршрутом. Индекс дорожки берётся из API, не из названия и не из её позиции на экране. Выбирается проверенный legacy HLS `master-v1aN`. Если он отсутствует, воспроизведение останавливается: подмена русским HLS2 запрещена.

Используется существующий публичный OAuth-клиент xbmc, присутствующий в проверенном плагине. Это общий идентификатор приложения, а не пользовательский токен. Вход выполняется штатной активацией устройства. Токены хранятся локально; запросы идут напрямую к api.service-kp.com. Автоматический перенос токенов Lampa не добавлен.

В HTML установлен CSP: локальные скрипты, единственный API-хост, без eval, сторонних скриптов и объектов. Медиа-URL допускаются только по HTTPS с известных CDN и API-хоста. Строгий список может отказать при смене официального CDN.

## Проверено

- На живом API Bleach 2004, первая серия: русская дорожка 1, японская 2, обе AAC stereo.
- Реальный media-links возвращает `files[].url`, а не ожидавшееся старым клиентом `files[].urls`. Исправлено в новом маршруте; тест воспроизводил отказ до исправления.
- Автотест через настоящий маршрутизатор клиента проверяет выбор серии, индекс API, сохранение подписи URL, блокировку чужих хостов и отказ без подмены языка.
- Официальный контракт MSX: https://msx.benzac.de/info/xp/actions.html — ответ video:resolve содержит url.

## Ещё не подтверждено

Физическое воспроизведение и слышимый японский звук внутри MSX на этом Samsung. Пульт подключён, но экран/инспектор недоступны, запуск нужного приложения не подтверждён. Прямая передача HLS через DLNA вернула ошибку 716 Resource not found; это отдельный проигрыватель, результат нельзя переносить на MSX.

Новый минимальный native-маршрут пока не передаёт позицию продолжения, не сохраняет прогресс и не подключает внешние субтитры. Поэтому это кандидат для проверки аудио, не полная функциональная замена установленной Lampa. Кнопки просмотра больше не обещают продолжение с сохранённой позиции.

Проверки: `node tests/security.mjs`, `node tests/native.mjs`.
